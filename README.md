# MHE 301 — Materials Handling Engineering / วิศวกรรมการขนถ่ายวัสดุ

เว็บไซต์เอกสารประกอบการสอนรายวิชา MHE 301 ระดับปริญญาตรี ภาคการศึกษาที่ 1 ปีการศึกษา 2569
เป็นเว็บไซต์แบบสถิต (static site) ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ HTML ในเบราว์เซอร์ได้ทันที

Course website for MHE 301, an undergraduate materials handling engineering course.
Static HTML, no build step and no external dependencies.

---

## โครงสร้างไฟล์ / Files

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` / `index-th.html` | หน้าแรกของรายวิชา |
| `syllabus.html` / `syllabus-th.html` | ประมวลรายวิชา เกณฑ์การประเมิน ระเบียบปฏิบัติ |
| `calendar.html` / `calendar-th.html` | ปฏิทินการเรียน 15 สัปดาห์ |
| `chapter1.html` / `chapter1-th.html` | บทที่ 1 ประเภทของอุปกรณ์ขนถ่ายวัสดุและการเลือกใช้ |
| `chapter2.html` / `chapter2-th.html` | บทที่ 2 เกลียวลำเลียง |
| `chapter3.html` / `chapter3-th.html` | บทที่ 3 สายพานลำเลียง |
| `chapter4.html` / `chapter4-th.html` | บทที่ 4 กระพ้อลำเลียง |
| `chapter5.html` / `chapter5-th.html` | บทที่ 5 การลำเลียงด้วยลม |
| `quiz1.html` … `quiz5-th.html` | แบบทดสอบทบทวนบทละ 40 ข้อ ทั้งสองภาษา |
| `style.css` | สไตล์ชีตร่วมของทุกหน้า |
| `lang.js` | คงตำแหน่งหัวข้อขณะสลับภาษา |
| `quiz.js` | เอนจินตรวจคำตอบของแบบทดสอบ |

ไฟล์ที่ลงท้ายด้วย `-th` คือฉบับภาษาไทย สลับภาษาได้จากปุ่ม **EN / ไทย** บนแถบด้านบน
โดย `id` ของหัวข้อตรงกันทั้งสองภาษา ผู้อ่านจึงอยู่ที่หัวข้อเดิมเมื่อสลับภาษา

## การเปิดใช้งาน / Viewing

เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือถ้าต้องการเสิร์ฟผ่าน HTTP

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## เนื้อหาที่เผยแพร่แล้ว

| บท | เรื่อง | สาระสำคัญ | สัปดาห์ |
|---|---|---|---|
| 1 | ประเภทของอุปกรณ์ขนถ่ายวัสดุและการเลือกใช้ | สมการการขนถ่ายวัสดุ รหัสวัสดุเทกอง หน่วยบรรทุกและพาเลท อุปกรณ์ทั้งห้าหมวดราวเจ็ดสิบชนิด พิกัดการยกของรถยก และกระบวนการคัดเลือกสองขั้นตอน | 1–2 |
| 2 | เกลียวลำเลียง | ชนิดใบเกลียว รหัสวัสดุ CEMA อัตราการบรรจุรางและกลุ่มชิ้นส่วน อัตราการลำเลียงและกำลังขับทั้งวิธี CEMA และเมตริก แรงบิดและการกำหนดขนาดชิ้นส่วน การแอ่นตัวและการสึกกร่อน เกลียวเอียงและแนวดิ่ง เกลียวป้อน | 3–4 |
| 3 | สายพานลำเลียง | ส่วนประกอบและโครงสร้างสายพาน อัตราการลำเลียงตาม ISO 5048 แรงต้านและกำลังขับตาม DIN 22101 การวิเคราะห์แรงดึงด้วยออยเลอร์ ชุดปรับความตึง การเลือกความแข็งแรงสายพาน การปรับแนวและความปลอดภัย | 5–7 |
| 4 | กระพ้อลำเลียง | การปล่อยวัสดุสี่ชนิดและจุดขั้ว (pole point) กระพ้อและระยะห่าง สายพานหรือโซ่ การป้อนแบบตักและแบบท่วม อัตราการลำเลียง กำลังขับ แรงดึง ชุดปรับความตึงและเบรกกันถอยหลัง การป้องกันการระเบิดของฝุ่น | 9 |
| 5 | การลำเลียงด้วยลม | ระบบความดันและสุญญากาศ เฟสเจือจางและเฟสหนาแน่น แผนภาพสภาวะและความเร็ว saltation อัตราส่วนบรรทุกของแข็ง การขยายตัวของอากาศและท่อขยายขั้น ความดันสูญเสีย เครื่องอัดอากาศ อุปกรณ์ป้อนและการรั่ว การกรอง การสึกหรอ ไฟฟ้าสถิตและการป้องกันการระเบิด | 10–11 |

ทุกบทมีตัวอย่างการออกแบบครบทุกขั้นตอน แบบฝึกหัดท้ายบท 20 ข้อ (บทที่ 1 และ 3 มี 10–12 ข้อ)
และแบบทดสอบทบทวนปรนัย 40 ข้อพร้อมคำอธิบายเฉลยที่เชื่อมโยงกลับไปยังหัวข้อที่เกี่ยวข้อง

บทที่ 6 โซ่ลำเลียงและสายพานแผ่นเหล็ก, บทที่ 7 ปั้นจั่นและเครื่องยก, บทที่ 8 รถอุตสาหกรรมและ AGV
และบทที่ 9 การจัดเก็บและคลังสินค้า อยู่ระหว่างจัดทำ

## มาตรฐานที่อ้างอิง

- ISO 5048 — การคำนวณกำลังใช้งานและแรงดึงของสายพานลำเลียง
- DIN 22101 — หลักเกณฑ์การคำนวณและกำหนดขนาดสายพานลำเลียงวัสดุเทกอง
- CEMA, *Belt Conveyors for Bulk Materials*, ฉบับพิมพ์ครั้งที่ 7
- CEMA 350 — เกลียวลำเลียง / CEMA 550 — กระพ้อลำเลียง
- ANSI/CEMA B20.1 — มาตรฐานความปลอดภัยของเครื่องลำเลียง
- DIN 15261 / 15262 — เกลียวลำเลียง, DIN 15234 — กระพ้อลำเลียง
- ISO 7119 — การคำนวณกำลังขับของเกลียวลำเลียงและกระพ้อลำเลียง
- NFPA 61 / NFPA 652 และ EN 14491 — การป้องกันการระเบิดของฝุ่น
- VDI 3676 / VDI 2263 — การลำเลียงด้วยลม และการระเบิดของฝุ่น
- CEN/TR 15281 — การแทนที่ด้วยก๊าซเฉื่อย, IEC 60079-32 — อันตรายจากไฟฟ้าสถิต
- ANSI/ITSDF B56.1 — ความปลอดภัยของรถยกอุตสาหกรรม

ค่าตัวเลขในตารางเป็นค่าตัวแทนเพื่อการเรียนการสอน **การออกแบบงานจริงต้องตรวจสอบกับมาตรฐาน
ฉบับทางการที่เป็นปัจจุบันและข้อมูลของผู้ผลิตเสมอ**
