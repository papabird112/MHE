# MHE 301 — Materials Handling Engineering / วิศวกรรมการขนถ่ายวัสดุ

เว็บไซต์เอกสารประกอบการสอนรายวิชา MHE 301 ระดับปริญญาตรี ภาคการศึกษาที่ 1 ปีการศึกษา 2569
เป็นเว็บไซต์แบบสถิต (static site) ไม่ต้องติดตั้งอะไรเพิ่ม เปิดไฟล์ HTML ในเบราว์เซอร์ได้ทันที

Course website for MHE 301, an undergraduate materials handling engineering course.
Static HTML, no build step and no external dependencies.

---

## โครงสร้างไฟล์ / Files

| ไฟล์ | คำอธิบาย |
|---|---|
| `index.html` / `index-th.html` | หน้าแรกของรายวิชา |
| `syllabus.html` / `syllabus-th.html` | ประมวลรายวิชา เกณฑ์การประเมิน ระเบียบปฏิบัติ |
| `calendar.html` / `calendar-th.html` | ปฏิทินการเรียน 15 สัปดาห์ |
| `chapter1.html` / `chapter1-th.html` | บทที่ 1 สายพานลำเลียง |
| `style.css` | สไตล์ชีตร่วมของทุกหน้า |
| `lang.js` | คงตำแหน่งหัวข้อขณะสลับภาษา |

ไฟล์ที่ลงท้ายด้วย `-th` คือฉบับภาษาไทย สลับภาษาได้จากปุ่ม **EN / ไทย** บนแถบด้านบน
โดย `id` ของหัวข้อตรงกันทั้งสองภาษา ผู้อ่านจึงอยู่ที่หัวข้อเดิมเมื่อสลับภาษา

## การเปิดใช้งาน / Viewing

เปิด `index.html` ด้วยเบราว์เซอร์ได้โดยตรง หรือถ้าต้องการเสิร์ฟผ่าน HTTP

```bash
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## เนื้อหาบทที่ 1

ส่วนประกอบสายพานลำเลียง โครงสร้างและการเลือกสายพาน การคำนวณอัตราการลำเลียงตาม ISO 5048
แรงต้านและกำลังขับตาม DIN 22101 การวิเคราะห์แรงดึงด้วยความสัมพันธ์ออยเลอร์ ชุดปรับความตึง
การเลือกความแข็งแรงสายพาน พร้อมตัวอย่างการออกแบบครบ 11 ขั้นตอน (โจทย์หินปูนบด 500 ตัน/ชั่วโมง)
และแบบฝึกหัด 10 ข้อ

บทที่ 2–8 อยู่ระหว่างจัดทำ

## มาตรฐานที่อ้างอิง

- ISO 5048 — การคำนวณกำลังใช้งานและแรงดึงของสายพานลำเลียง
- DIN 22101 — หลักเกณฑ์การคำนวณและกำหนดขนาดสายพานลำเลียงวัสดุเทกอง
- CEMA, *Belt Conveyors for Bulk Materials*, ฉบับพิมพ์ครั้งที่ 7
- ISO 10247 / DIN 22102 — การจำแนกชั้นยางหุ้มสายพาน

ค่าตัวเลขในตารางเป็นค่าตัวแทนเพื่อการเรียนการสอน **การออกแบบงานจริงต้องตรวจสอบกับมาตรฐาน
ฉบับทางการที่เป็นปัจจุบันและข้อมูลของผู้ผลิตเสมอ**
